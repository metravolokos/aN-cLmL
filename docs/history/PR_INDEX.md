## Goal
Validate whether Codex Cloud can access Cloud Mail.ru WebDAV for the isolated M0 stage. This is an intentionally small, dependency-free Python read-only probe; it is not the future application.

## Acceptance

## [#12](https://github.com/metravolokos/cloudmail-player-m0/pull/12): Prevent playback restart after Stop during async track opening

Status: merged; head `9403c10adf09ca251dd4ea044a13ffead90453d1`.

## Bug
`PlaybackController._open()` awaits cache setup and `setAudioSource`. Previously `stop()` could complete during either await, after which `_open()` could still invoke `player.play()`, unexpectedly restarting playback.

## Fix
Add a monotonic operation generation invalidated on Stop and provider disposal. After async cache preparation and after audio source initialization, stale opens are rejected; stale source setup actively stops the player. Does not change the 64 KiB WebDAV transport or cache policy.

## Verification
