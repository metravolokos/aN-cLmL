# Product specification — baseline

The full initial user instructions described a Windows + Android (no GMS) music player with one Flutter codebase, backed solely by Cloud Mail.ru WebDAV folder /AllMusic.

## Requirement register

- FR-001: Connect securely to the user's Cloud Mail.ru WebDAV; the music root is /AllMusic only.
- FR-002: Display Tracks, Albums and Artists; Artist → Albums → Tracks, Album → Tracks.
- FR-003: Read media tags and covers with partial ranged fetches; retain SQLite index and perform incremental background sync, with cancellation.
- FR-004: Play MP3/FLAC/M4A(AAC)/OGG(Opus)/WAV using queue context, seek, pause, next/previous; support shuffle and repeat.
- FR-005: Cache artwork with 1200px maximum side and JPEG quality 85; limit with LRU.
- FR-006: Temporarily cache only current and next audio track with hard size limit and cleanup.
- FR-007: Android MediaSession/mediaPlayback foreground service and headset controls; Windows system media controls.
- FR-008: Adaptive UI with Android bottom navigation and Windows rail; full player and persistent mini-player in playback stages.
- FR-009: No playlists, favorites, telemetry, analytics, GMS, or Google-dependent runtime.
- FR-010: Securely store credentials via OS secret storage, never in repository/logs.
- NFR-001: English source/docs and Russian app UI via ARB localization.
- NFR-002: Readable code organization with presentation/data/domain boundaries; no business logic in widgets.
- NFR-003: Local/CI tests, analyzer, signed release APK and Windows binary; no false claims about untested platforms.

## M1 acceptance slice

- M1-001: One root Flutter project with generated android/ and windows/ runner directories; minSdk >=24; no GMS dependencies.
- M1-002: Russian ARB localization and app display strings generated by Flutter's l10n tool; theme styles use Material 3.
- M1-003: Adaptive navigation: bottom bar for narrow Android layouts, NavigationRail or sidebar for desktop widths.
- M1-004: Functional switching between four destinations: Tracks, Albums, Artists, Settings; honest empty states until M2/M3.
- M1-005: Light/dark/system theme switching, simple state management and injectable interfaces for future services.
- M1-006: Widget tests covering screen switching, narrow/wide layout, and theme; static analyzer passes.
- M1-007: Recorded Flutter/SDK versions; Flutter pub dependencies locked; Android build validated when SDK available; Windows build via Windows runner.
- M1-008: README, AGENTS, STATUS, ROADMAP, ADR and minimum CI updated to match actual code and honest test evidence.

No requirement to implement media playback, fake library data or cloud login in M1.
